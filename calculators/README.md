# Utility Calculator Index

CalciHub currently provides 5 utility calculators.

- [GPA Calculator](https://calcihub.com/calculators/gpa)
  - Calculate weighted GPA from grades and credit hours.
- [Grade Calculator](https://calcihub.com/calculators/grade)
  - Calculate weighted grades or determine what is needed on a final exam.
- [Password Generator](https://calcihub.com/calculators/password)
  - Generate strong random passwords directly in the browser.
- [Subnet Calculator](https://calcihub.com/calculators/subnet)
  - Calculate network address, broadcast address, host range, and subnet mask.
- [Love Calculator](https://calcihub.com/calculators/love)
  - A simple entertainment calculator based on two names.
