# Utility Calculator Index

CalciHub currently provides 5 utility calculators for education, networking, security, and everyday use.

- [GPA Calculator](https://calcihub.com/calculators/gpa) — Calculate weighted GPA from grades and credit hours.
- [Grade Calculator](https://calcihub.com/calculators/grade) — Calculate weighted grades or determine the score needed on a final exam.
- [Password Generator](https://calcihub.com/calculators/password-generator) — Generate strong random passwords in the browser.
- [Subnet Calculator](https://calcihub.com/calculators/subnet) — Calculate network address, broadcast address, host range, and subnet mask.
- [Love Calculator](https://calcihub.com/calculators/love) — A simple entertainment calculator based on two names.
